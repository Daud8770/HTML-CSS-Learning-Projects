# HTML & CSS Learning Projects

A collection of small HTML and CSS projects built while learning front-end web development, from basics to advanced concepts.

## Projects

| # | Folder | Description |
|---|--------|-------------|
| 1 | `02 - Card` | Card layout built with HTML and CSS |
| 2 | `03 - Parallax` | Parallax scrolling effect page |
| 3 | `04 - Mug Card` | Product card design for a mug |
| 4 | `05-Image Gallery` | Responsive image gallery layout |
| 5 | `Modern_Chair` | Modern chair product landing page |
| 6 | `Tribute_Page` | Tribute page dedicated to a person |

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, positioning, transitions)

## What I practiced

- Page structure with semantic HTML
- Layouts using Flexbox and Grid
- Responsive design
- Hover effects and transitions
- Background images and parallax effect

## How to run

1. Clone the repository:

   ```bash
   git clone https://github.com/Daud8770/HTML-CSS-Learning-Projects.git
   ```

2. Open any project folder.
3. Double-click `index.html` to open it in your browser, or use the **Live Server** extension in VS Code.
